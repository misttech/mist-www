# mist-www

The Mist product hub, published to GitHub Pages at
[www.mist-os.com](https://www.mist-os.com/).

## No build step

The site is HTML and CSS, served exactly as written. There is no static site
generator, no bundler, and no dependency to update.

```sh
make serve     # http://localhost:8000
```

## Domain

`CNAME` declares `www.mist-os.com`. Until DNS and GitHub Pages HTTPS are
configured, the github.io URL is
`https://misttech.github.io/mist-www/`.
